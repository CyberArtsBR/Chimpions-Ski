# Chimpions Ski

A modern 3D endless downhill ski game built around The Chimpions.

## v0.1 goal

- endless downhill movement
- left/right carving
- trees and rocks
- ramps and airtime
- bananas
- increasing speed
- crash / restart loop
- real rigged Chimpion GLB support
- keyboard, controller and touch-ready architecture
- Vite + Three.js
- Render-ready deployment

This repository is intentionally separate from Chimp Jump while reusing the proven Chimpion asset pipeline and web-game architecture.
